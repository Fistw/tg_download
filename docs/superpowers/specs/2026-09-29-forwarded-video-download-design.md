# 转发视频直接下载功能设计

**日期：** 2026-09-29

**状态：** 已获设计确认

## 目标

允许白名单用户把 Telegram 视频转发给 Bot，Bot 将收到的视频保存到 `download.output_dir`（服务器当前配置为下载目录），并回复保存结果。Bot 只保存到服务器，不再把视频回传给发送者。

## 方案

由 Bot 的 `NewMessage` 处理器处理收到的媒体消息，直接使用 Bot 客户端下载该消息的媒体。这样下载的是 Bot 实际收到的文件，不依赖转发来源是否公开、是否显示来源，或用户会话能否访问原消息。

处理流程：

1. 仅处理来自 `bot.allowed_users` 的入站消息。
2. 识别 Telegram 标记为视频的媒体，以及 MIME 类型为 `video/*` 的文档；纯链接和非视频内容不进入下载流程。
3. 将视频保存到配置的下载目录。保留可用的原文件名并清理不安全字符；文件名带上聊天 ID 和消息 ID，避免同名覆盖。
4. Telegram 相册中的每条视频消息独立下载并单独回复。
5. 下载成功时回复保存文件名；失败时回复简明错误，并清理本次产生的不完整文件。

## 权限与兼容性

- 非白名单用户不能触发下载。
- 转发给 Bot 的原始媒体必须仍可由 Bot 读取；纯文本链接不属于此功能。
- 现有 `/download <链接>` 和直接发送 `t.me` 链接的行为保持不变。
- 不新增数据库表或配置项。

## 验证

- 验证白名单用户转发的视频会出现在配置下载目录，并收到完成回复。
- 验证一个相册中的多个视频分别保存。
- 验证非视频消息不会被保存，下载失败会返回错误且不留下部分文件。
- 部署后确认 `tg-download.service` 正常运行。
